RAYAN BIRTHDAY WEBSITE - GitHub Pages package

HOW TO PUBLISH
1. Create a new GitHub repository (public).
2. Upload EVERYTHING inside this folder (index.html, .nojekyll, assets/ and README.txt).
   index.html must be in the top level of the repository.
3. Repository Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root) > Save.
4. After a minute your site is live at https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

NOTES
- index.html is fully self-contained: every image, sticker, song, sound and the cat video are embedded in it,
  so nothing can go missing or break because of a wrong file path.
- The assets/ folder holds the same files separately as a backup / for reference. The website does not load from it.
- Fonts (Nunito, Fredoka) load from Google Fonts when online; the site falls back to a standard font if offline.
- Open the link on a phone and tap once on the page before expecting sound (phones require a tap before audio).
